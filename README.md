# Маркирование и верификация цифровых изображений

Программный комплекс из двух CLI-утилит для встраивания и слепого извлечения
цифрового водяного знака (ЦВЗ) в изображения.

Схема: **DWT (HL1) → DCT 8×8 → QIM** в канале яркости (Y),
криптографическая подпись **Ed25519** и помехоустойчивое кодирование **Reed-Solomon**.

## Возможности

- Встраивание ЦВЗ только в канал яркости **Y** (цветность U/V не изменяется).
- Детерминированный пакет фиксированного размера (800 бит).
- Криптографическая аутентификация метки (Ed25519) — подделка невозможна без закрытого ключа.
- Помехоустойчивость RS(100,70): исправление до 15 полностью битых байт.
- **Слепое** извлечение — исходное изображение не требуется.
- Сохранение результата только в форматах без потерь (PNG/TIFF/BMP).

## Использование

### Встраивание (`embedder.py`)

```bash
python embedder.py -i input.png -m 12345 -o marked.png -k private_key.pem --delta 30
```

| Аргумент | Обяз. | Описание |
|---|---|---|
| `-i`, `--input` | да | Исходное изображение |
| `-m`, `--message` | да | ID автора (число или строка) |
| `-o`, `--output` | да | Результат (PNG/TIFF/BMP) |
| `-k`, `--key` | нет | Закрытый ключ Ed25519 (PEM). Если не задан — генерируется новая пара в текущем каталоге |
| `--delta` | нет | Шаг квантования QIM (по умолчанию `30`) |

Если `-k` не указан, рядом создаются `private_key.pem` и `public_key.pem`,
а путь к публичному ключу выводится на экран.

### Извлечение и проверка (`detector.py`)

```bash
python detector.py -i marked.png -k public_key.pem
```

| Аргумент | Обяз. | Описание |
|---|---|---|
| `-i`, `--input` | да | Анализируемое изображение |
| `-k`, `--key` | да | Открытый ключ Ed25519 (PEM) |
| `--delta` | нет | Шаг QIM (должен совпадать с `embedder.py`) |

### Пример вывода

```
[OK] Метка встроена.
    ID: 12345
    Канал: Y, поддиапазон HL1, DCT 8x8, коэф. (4, 4), delta=30
    Файл: marked.png
```

```
[SUCCESS] Изображение подтверждено. ID: 12345
```

Возможные ошибки детектора:

```
[FAIL] Метка разрушена или отсутствует   # RS не смог восстановить пакет
[FAIL] Подпись недействительна           # пакет цел, но подпись не сходится
```

## Формат полезной нагрузки

| Компонент | Размер |
|---|---|
| Ядро: маркер `0x49 0x41` + ID | 6 байт |
| Подпись Ed25519 | 64 байта |
| **Payload до коррекции** | **70 байт** |
| Reed-Solomon RS(100,70) | +30 байт |
| **Итоговый пакет** | **100 байт = 800 бит** |

Сообщение `-m`: если это целое число `0…2³²−1` — кодируется big-endian (`>I`),
иначе берутся первые 4 байта `sha256(строка)`.

## Алгоритм

### Встраивание

1. Формирование payload: `magic + ID` → подпись Ed25519 → RS(100,70) → 800 бит.
2. `RGB → YUV`; встраивание только в канал **Y**.
3. Одноуровневый 2D-DWT (`haar`, `periodization`) → поддиапазон **HL1**.
4. Разбиение HL1 на блоки 8×8 → 2D-DCT (ортонормальный).
5. QIM в коэффициенте `[4,4]`: чётное кратное Δ → бит `0`, нечётное → бит `1`.
6. Обратные IDCT → IDWT → сборка YUV → RGB → сохранение.

### Извлечение

1. `RGB → YUV → Y → DWT → HL1 → блоки 8×8 → DCT`.
2. Считывание коэффициента `[4,4]`: бит по ближайшей (чётной/нечётной) сетке Δ.
3. 800 бит → 100 байт → декодирование Reed-Solomon.
4. Разделение ядра и подписи → верификация Ed25519 → вывод ID.

## Замечания

- Изображение должно вмещать **≥ 800 блоков** 8×8 в поддиапазоне HL1.
  Практически подходит изображение примерно от `512×512` и больше.
- `--delta` управляет устойчивостью/незаметностью: больше Δ — устойчивее к атакам,
  но заметнее артефакты. Значение обязано совпадать в обеих утилитах.
- Для корректной работы стеганоканала DCT применён в ортонормальной форме
  (`norm="ortho"`): иначе вклад одного коэффициента в пиксели слишком мал и
  QIM-правка стирается округлением до `uint8`.
- **Никогда не публикуйте `private_key.pem`** — он добавлен в `.gitignore`.
